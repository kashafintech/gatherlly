# Required Submission Screenshots

Capture genuine screenshots from the running application before submission. Do not use mockups or screenshots that imply an unverified production deployment.

Recommended captures:
1. Administrator dashboard with test events.
2. Event creation form and successful created event.
3. Employee dashboard and event list.
4. Employee registration list after registering.
5. Swagger UI at `/docs`.
6. Example validation/conflict response.

Use synthetic names and data. Do not include credentials, tokens, secret values, or real employee information.
